# Kuidas õppida

Väike õpioskuste juhend kutseõppijatele. Enne kui asume käske, tööriistu ja mõisteid õppima, teeme selgeks kõige tähtsama tööriista — **õppija enda õppimise**.

## Mis see on

Lühike, visuaalne veebimaterjal (6 lühilehte), mille õpilane loeb kursuse alguses või mille juurde saab aasta jooksul tagasi tulla. See vastab küsimusele *"kuidas ma üldse õpin?"* — mida enamikule pole kunagi õpetatud.

Teemad:

- **miks** sa õpid ja miks ebamugavus alguses on normaalne
- kuidas aju päriselt õpib — meenutamine, jaotatud kordamine, "raske = õpid"
- kuidas konspekteerida (Cornell, mõttekaart jm)
- praktilised nipid: prokrastinatsioon, puhkus, fookus
- prinditav töövihik: eesmärk, plaan, peegeldus

## Kellele ja miks

- **Õpilastele** — üks koht, kus on ausalt öeldud, mis õppimisel töötab ja mis mitte (nt "õpistiilid" on müüt; ülelugemine petab).
- **Õpetajale** — sama sait sobib linkida iga noortekursuse algusesse; ei pea igal aastal uuesti seletama.

## Millel see põhineb

Sisu põhineb **õppeteadusel, mitte mass-meedia arvamusel**. Faktid on eelretsenseeritud uuringutega viidatud (vt lehte *Allikad*); populaarteaduslikud videod on eraldi ja selgelt märgitud sissejuhatusteks, mitte tõenduseks.
